桌面 Code OAuth 缓存：身份白名单仅提取默认桌面 config.json 的 oauth:tokenCache 加密字段，随既有桌面登录与 Safe Storage 保存/清除/恢复；不覆盖其他设置。空键集整文件及额外字段拒绝，旧档案缺字段仍可恢复但不沿用当前账号缓存。隔离回归覆盖往返、回滚与旧档案缺失；不承诺服务端已过期登录可恢复。
login.rs: 仅 macOS 默认原生 CLI 2.1.307 的显式受控官方登录；私有 BROWSER 接收器、默认 open 回退阻断、10 分钟超时/取消、官方状态/目标邮箱核对；不返回授权链接、不归档，取消可能晚于官方凭据写入。
association.rs: 显式单端更新当前绑定目标的原槽位；先验收旧档案，仅捕获指定端、保留另一端旧资料，账号/组织冲突或未知拒绝 CLI 关联，App 只记用户核对；进程/资料/凭据复查与 SQLite 原子提交，不停止客户端、不改变工作区或 B 选择。
mod.rs: 当前/空/已保存身份与停止/原地备份/切换/恢复/重命名/删除 Tauri 命令，复用 Cleaner 全局事务锁；普通刷新仅读 SQLite 和本地显示元数据，不打开 Store、不解密归档或回填摘要；进程预览至多 32 项，失败为 null 且停止状态保守未知；UI 不接收凭据正文。
database.rs: 默认开启联动且保留显式关闭，SQLite v3 管理稳定槽位、不可变归档代次、HMAC 索引与持久恢复状态；脱敏摘要读时重算本地过期状态，旧摘要未知；原地备份同事务提交档案/名称/摘要；迁移严格新增身份/摘要/可选绑定并拒绝已存账号，均不改选择指针，凭据正文不入库。
store.rs: 原地加密备份只提交档案、不切换浏览器或清工作区；先验收归档再切换、失败回滚、独立恢复检查点与显式删除；迁移打开方式拒绝 recovery 且不回收旧暂存/归档或解包建索引；旧归档瞬态锁不恢复，非空同名目录按用户策略保留，清除/恢复按真实源计数，关键阶段及每 250ms 复查进程；凭据修改和备份/切换/恢复提交前再次复查，已观察到的进程冲突在当前 Store 中锁存，禁止随后自动回滚，保留持久恢复记录；切换/恢复每轮同时检查当前与目标 B 资料；关闭联动不增加 B 限制，同槽位不改凭据的重选仍可在 CLI 活跃时完成；不声称轮询消除了外部启动竞态。
profile.rs: 只读显示白名单与本地凭据订阅/过期元数据，已认证归档生成脱敏摘要；状态只表示 local_unexpired/expired/refresh_available/api_key/unknown，不联网、不承诺自动续期，未知过期时间及旧摘要降级未知；API-only 设置仍是身份；只展示真实进程名/PID，不从可能复用 PID 的旧会话文件猜测工作区，不打开系统钥匙串或 Cookie。 新增 CLI/Desktop 当前与归档资料标记，普通刷新不读 Keychain/Cookie；macOS 缺文件不判无钥匙串，旧摘要缺字段为未知，Desktop 元数据不安全为未知。
credentials.rs: 默认 Code 凭据按用户策略合并身份与共享 MCP/插件秘密；正文只在原生内存流动。
Desktop 授权保留：正常切换、回滚及恢复仅在目标具有同 service/account 的 Claude Safe Storage 时，先校验并保留现有条目，再通过既有 expected 值检查原地更新密钥；不从归档导入 ACL，不新增信任应用。空身份、直接删除和无对应目标仍删除，Code 清理策略不变。首次授权、临时签名新构建、删除后重建仍可能需要系统确认。
archive.rs: 新身份复用空浏览器预留编号；新快照排除固定锁的普通文件/空目录，不删除原件；tar/Zstd 与旧 gzip 兼容验收，代次与卡片编号分离；被拒绝源报告具体路径；源文件写完才递增完成数，压缩/认证落盘和完整解包验收分阶段报告，完整认证后才交目录事务。
catalog.rs: 无账号元数据时，仅复用明确选择且原本也未知账号的本地档案；已识别其他账号优先，不按名字合并；有界读取账号 UUID/组织（缺失时邮箱/组织），以本机 HMAC 匹配稳定槽位；显式事务打开 Store 时仅为缺账号索引的旧副本验收建索引，缺摘要不强制解密；提交后去重/回收，未知账号与恢复检查点不猜测合并，Desktop-only 暂存保守保留。
compression.rs: Zstandard 级别 3 流式压缩与校验和，读取侧限制窗口并按魔数兼容旧 gzip；外层认证协议不变。
save_integrity_tests.rs: 新增人工维护窗口内完整 CLI/Desktop/B → 仅浏览器 → 完整身份往返、缺失端活动登录清除与两份 Cookie 保留； 保留对抗性保存反例；覆盖所选历史不回灌/不丢失、真正空工作区仍可恢复、保留策略、重新联动后的真实资料绑定、事务故障重试、CLI/Desktop 归档内容与跨账号隔离。

optimization_tests.rs: 共享虚构账号夹具、A/B 连续切换、原地备份不动工作区与浏览器指针、缺摘要惰性保留、空身份往返、主目录历史备份删除后恢复与路径边界、仓库路径/代理和跨应用不同账号资产保留、三平台路径契约、凭据刷新、跨组织隔离、崩溃恢复及压缩认证兼容；手动 500 会话性能样本不设 CI 时间阈值。

本机链接兼容：Unix 仅在已白名单确认的普通源目录内部保存链接本身（含失效/外部目标），不访问目标。带链接归档 manifest v2，完整认证与成员验收后才在暂存区创建链接；根路径、JSON 源、链接父路径写入、硬链接和特殊文件仍拒绝。v1 继续可读；v2 暂不导出到跨设备迁移包。普通刷新另返回最后提交的本地档案选择，与账号 HMAC 匹配严格分开，不据此合并未知账号。

State.workspace_id 来自与 snapshot_record 相同的账号/本地槽位解析，独立于 active 云账号匹配；元数据不可读或无本地状态时不宣称当前档案。

可选跨设备浏览器配置继续排除网络设置：DoH 与代理均不导出；导入 DNS 默认沿用目标资料原有解析。

本机浏览器身份保存：已联动且实际存在的当前 profile 也属于可保存状态；即使 Claude 源/凭据为空，命名身份不能被 empty 清理。原地保存只在当前资料尚未绑定时建立关联，不抢占其他身份的浏览器，不改 active/浏览器选择。无账号元数据时可从当前独占绑定找回已存本地卡片；账号匹配仍优先，不把本地关联当成云端认证。浏览器文件仍留在本机，不进入 Claude 加密归档。真正无资料的切换不再声称已保存原身份。

保存完整性：同一未知账号本地档案重选时，所选历史等非登录资料也阻止旧快照回灌；真正无资料仍允许恢复。联动开启且 active 的原绑定与当前资料不一致时不复用旧档案，当前资料另存并通过其独占绑定稳定更新；旧档案、浏览器目录和种子保留，不按名称合并、不抢占其他账号绑定。

desktop_sessions.rs: macOS 默认 Claude 的可选本地会话同步；共享默认关闭，补齐入口和层级。不同正文版本读取消息 UUID/时间，完整消息后继或明确回退且旧分支未再写入时自动跟进；真正分叉/无法确认前后继时先返回选择，不改身份。选择绑定索引与正文摘要，资料变化须重新选择。同步 cliSessionId、priorCliSessionIds、rewindEdges、transcriptCuts 等窄续聊字段，保留目标权限、标题、已脱离关系；不复制登录、定时任务或会话授权。替换前把完整旧索引保存在对应账号目录的私有 .baga-history，正文不改。停止检查、源/目标复核和部分成功计数保持；大于 128 MiB 或无法读取的待比较正文不自动裁决。
